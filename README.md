# Carnivore
Сайт управления бронированием столиков для ресторана, построенный на Django. Включает в себя функционал бронирования, управления контентом сайта, обратной связи и управления пользователями с разграничением прав.

# 🚀 Основные возможности

Бронирование столиков: Выбор даты, времени, продолжительности и стола с проверкой доступности

Управление пользователями: Регистрация, верификация email, восстановление пароля, система ролей

Управление контентом: Карусель изображений, описание ресторана, история, миссия, контакты

Обратная связь: Форма для связи с администрацией

Управление услугами: Создание и редактирование дополнительных услуг ресторана

Административная панель: Управление бронями, пользователями и контентом

# 🛠 Технологический стек
Backend: Django 5.2.3, Django REST Framework

Database: PostgreSQL

Authentication: JWT (Simple JWT)

Web server: Nginx

Email: Yandex SMTP

Deployment: Docker, Docker Compose

# 📋 Предварительные требования

Docker

Docker Compose

# ⚙️ Настройка переменных окружения
Создайте файл .env в корневой директории проекта со следующими переменными:

env

    DB_NAME=your_db_name
    DB_USER=your_db_user
    DB_PASSWORD=your_db_password
    DB_HOST=db
    DB_PORT=5432
    APP_EMAIL=your-email@yandex.ru
    EMAIL_PASS=your-email-password

# 🐳 Запуск через Docker Compose
## 1. Клонирование и настройка

#### Клонируйте проект
    git clone https://github.com/Arty525/Python_DP

#### Создайте .env файл как указано выше

## 2. Запуск контейнеров

### Запуск всех сервисов
    docker-compose up -d

### Или с выводом логов
    docker-compose up
## 3. Выполнение миграций и создание суперпользователя

#### Выполнение миграций
    docker-compose exec web python manage.py migrate

#### Создание суперпользователя
    docker-compose exec web python manage.py createsuperuser

#### Загрузка начальных данных (столы)
    docker-compose exec web python manage.py add_tables

#### Создание групп пользователей
    docker-compose exec web python manage.py create_user_groups

## 4. Доступ к приложению
После успешного запуска приложение будет доступно по адресам:

Основное приложение: http://localhost:8080

Админка Django: http://localhost:8080/admin

# 🚨 Возможные проблемы и решения

### Проблема: Ошибка подключения к базе данных
Решение: Убедитесь, что переменные DB_* в .env корректны и контейнер с PostgreSQL запущен.

### Проблема: Email не отправляются
Решение: Проверьте настройки Yandex почты и правильность пароля приложения.

### Проблема: Статические файлы не загружаются
Решение: Выполните docker-compose exec web python manage.py collectstatic.
